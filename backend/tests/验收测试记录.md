## 步骤与预期

### TC-01 正常生成

步骤：编辑创建书名、作者、50 字以上简介和风格，发起 AI 处理。本测试使用 mock，不调用大模型。

预期：返回 3 组候选，书名与所选风格一致，状态为待处理，selected 为 -1，并保留原始生成版。

实际：HTTP 200，状态 待处理，候选 3，标签 ['温暖治愈', '温暖治愈·2', '温暖治愈·3']

### TC-02 必填项缺失

步骤：分别提交空书名、发起时空简介、空风格、空作者。

预期：请求被拒绝并返回对应字段，不创建生成记录。

实际：书名 422 {'title': '请输入书名'} / 简介 422 {'intro': '请填写内容简介，不可在缺少简介时发起 AI'} / 风格 422 {'styles': '请至少选择一个风格标签'} / 作者 422 {'author': '请输入作者'}

### TC-03 资料不足

步骤：简介仅 6 字，其余必填项完整，发起 AI 处理。

预期：任务失败，错误码 E-DATA-01，不生成候选，不调用文案生成，不增加重试次数。

实际：HTTP 200，状态 失败，重试 0，调用 ['check_completeness']

### TC-04 工具参数错误

步骤：依次提交未允许工具、错误资料 ID、未选风格、未读稿就检查、错误字数、过早生成、错误数量和错误批次。

预期：非法参数返回拒绝原因且不执行；当前任务的资料 ID 可以被接受。

实际：全部拒绝符合预期

### TC-05 超时

步骤：勾选演示模型超时发起一次；另一任务先生成并提交人工版本，再以超时方式重试。

预期：超时任务失败且错误码为 E-MODEL-01，不产生原始生成版；已有人工版本仍在。

实际：新任务状态 失败；重试后状态 失败，版本 ['原始生成版', '编辑修改版']

### TC-06 结果依据不一致

步骤：一组候选把书名写成另一本书；另一组正文写入资料中没有的“国际大奖”。

预期：书名改回当前任务；无依据的奖项声明被拒绝，不写入候选。

实际：另一本书已改回「验收依据」，「国际大奖」未写入候选

### TC-07 越权

步骤：主编创建任务；另一名编辑修改、生成、提交；任务创建人自己审核；另一名编辑查询任务列表。

预期：上述请求均返回 403，另一名编辑的列表中看不到该任务。

实际：主编创建 403 / 他人修改 403 / 他人生成 403 / 他人提交 403 / 编辑审核 403 / 列表隔离 True

### TC-08 重复提交

步骤：完成生成、选定、筛查并提交一次后，用同一任务再次提交。

预期：第一次进入待审核；第二次返回 400，版本数量不增加。

实际：首次状态 待审核，再次 HTTP 400 该任务已提交审核，不能重复提交。，版本 2 -> 2

### TC-09 版本查询

步骤：查询已提交任务的版本，并分别用主编和另一名编辑读取任务列表。

预期：至少两版可查，含操作人与时间；主编可见同一版本，另一名编辑不可见。

实际：版本 ['原始生成版', '编辑修改版']，操作人与时间齐全，主编看到同一组版本，另一名编辑不可见

### TC-10 敏感词工具超时

步骤：选定候选后，以演示超时调用敏感词筛查。

预期：任务失败，错误码 E-TOOL-01，结果不显示为通过。

实际：HTTP 200，状态 失败，错误 E-TOOL-01，提示 E-TOOL-01 · 本地规则工具超时，任务已置为失败。

## 缺陷与修复

1. 只选择一个风格时，模拟生成的第 2、3 组会标成没有选中的「文学叙事」「悬念引导」。已改为只使用所选风格的可区分标签。回归用例 TC-01。
2. 模型若把书名写成另一本书，或在正文写入资料中没有的「国际大奖」等依据，原先会把正文原样保存。现已把书名改回当前任务，并拒绝无依据声明，不写入候选。回归用例 TC-06。
3. 已提交任务再次提交时，提示仍是「请先完成编辑」。已改为明确返回「不能重复提交」，并且不新增版本。回归用例 TC-08。

## 回归

上述 3 项修复后重新执行本脚本。10 条用例全部通过，未再出现原缺陷。
